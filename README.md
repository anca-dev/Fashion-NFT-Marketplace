# Fashion NFT Marketplace

A decentralized marketplace for fashion NFTs built on Stacks blockchain using Clarity smart contracts.

## Features

- **NFT Minting**: Fashion designers can mint their creations as unique NFTs.
- **Marketplace Trading**: Secure buying and selling with STX payments
- **Royalty System**: Automatic royalty distribution to original designers
- **Metadata Storage**: Comprehensive item information including category and rarity
- **Owner Verification**: Secure ownership tracking and transfer mechanisms

## Contract Functions

### Public Functions
- `mint-fashion-nft`: Create new fashion NFTs with metadata
- `buy-nft`: Purchase NFTs from the marketplace

### Read-Only Functions
- `get-token-metadata`: Retrieve NFT metadata
- `get-token-price`: Get current NFT price
- `get-next-token-id`: Get the next available token ID

## Usage

Deploy the contract and start minting fashion NFTs with detailed metadata including designer information, category, and rarity levels.
